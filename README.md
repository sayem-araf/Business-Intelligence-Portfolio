# Project: US Retail Sales Dashboard

**Description:**  
This Power BI dashboard visualizes sales performance for a US retail store. The dataset included separate tables for customers, sales, and regional information. Data was cleaned and transformed in Power Query, a data model was created linking all tables with calculated measures, and key metrics were visualized to support business decision-making.


**Techniques used:**  
- Data cleaning and transformation with Power Query  
- Data modeling: linked tables, relationships, and calculated measures  
- Visualization of KPIs, trends, and regional sales comparisons in Power BI  
- Advanced Excel analysis for additional insights and KPI calculations

**Files included:**  
- `Food_Mart_BI` – Power BI file with data, model, and visuals
